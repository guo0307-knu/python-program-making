# 기계재료 물성치 검색 프로그램 (Material Property Search Tool)

## 무엇을 하는 프로그램인가요?
이 프로그램은 기계공학 전공 과제 및 문제 풀이 시 자주 참조하는 다양한 재료(강철, 알루미늄 등)의 물성치를 효율적으로 관리하고 검색하기 위해 개발되었습니다. 복잡한 표 데이터를 파이썬 딕셔너리 구조로 체계화하여, 재료명 검색, 전체 검색 가능 목록 제공, 그리고 공학 단위 변환(MPa ↔ kpsi, m ↔ inch, °C ↔ °F) 기능을 제공하여 공학 문제 풀이의 생산성을 높여줍니다.

## 실행 방법
1. **환경 설정**: Python 3.6 이상의 버전이 설치되어 있어야 합니다.
2. **파일 준비**: `data.py`, `functions.py`, `main.py` 파일이 같은 폴더에 있는지 확인합니다.
3. **실행**: vscode나 다른 파이썬 실행 프로그램을 통해 파일을 실행

## 사용된 Python 개념
- **자료구조**: 리스트(List), 딕셔너리(Dictionary)를 활용한 데이터베이스(EvenData) 구축
- **모듈화**: `import`문을 활용한 코드의 역할별 분리 (데이터, 기능, 실행부)
- **제어문**: `while` 루프 및 `if-elif-else`를 통한 프로그램 흐름 제어
- **함수(Function)**: 코드 재사용성과 가독성을 위한 기능별 함수 정의
- **예외 처리**: `try-except` 및 입력 검증(`strip`, `lower`)을 통한 안정적인 사용자 인터페이스 구현
- **문자열 처리**: `.strip()`, `.lower()` 메서드를 활용한 데이터 정제 및 안전한 검색
