# 프로젝트 이름 : 테이블 파인딩 프로그램

기계 공학 문제를 풀 때 쓰이는 재료의 물성치(ex : SAE 2340 steel의 ultimate strengthe)를 찾는 프로그램

기계 공학 문제를 풀 때 책 맨 뒤에 있는 테이블을 통해 물성치를 찾아야 하는데 테이블의 수도 많고 눈으로 한번에 찾기 어렵고 시간도 많이 소요되기 때문에 프로그램을 통해 만들어서 쉽게 찾기 위해 만들고자 함

## 핵심 기능

1. 물성치 검색 기능: 재료의 이름을 입력했을 때 확인하고자 하는 물성치를 바로 보여주는 기능
2. 재료 종류 확인 기능: 재료의 종류를 보여주는 기능
3. 전체 목록 확인 기능: 프로그램이 찾을 수 있는 것을 목록으로 보여주는 기능

## 예상 사용자 
나 및 기계공학부 학생들

## 결과물 형태
CLI 환경

## 사용할 PYTHON 개념
Dictionary, 함수, 리스트 등
