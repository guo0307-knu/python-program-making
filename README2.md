# 🚀 프로젝트 기획서: 기계재료 물성치 검색 프로그램 (Table Finder)

## 1. 기능 우선순위 목록

| 우선순위 | 기능명 (목적어 + 동사) | 세부 설명 및 필요 기술 |
| --- | --- | --- |
| **MUST**<br>

<br>(반드시) | **데이터베이스 구축** | 프로그램 실행 시 재료명(Key)과 물성치(Value)가 매핑된 딕셔너리(`EvenData`)를 메모리에 올립니다. |
| **MUST** | **메인 메뉴 출력** | CLI 환경에서 사용자가 선택할 수 있는 옵션(1. 검색, 2. 카테고리, 3. 전체목록, 4. 종료)을 텍스트로 보여줍니다. |
| **MUST** | **사용자 입력 수신** | `input()` 함수를 사용해 사용자가 원하는 메뉴 번호나 재료 이름을 텍스트로 입력받습니다. |
| **MUST** | **물성치 데이터 검색** | 입력받은 재료명을 Key로 삼아 `EvenData` 딕셔너리에서 해당하는 Value(항복강도 등)를 찾습니다. |
| **MUST** | **검색 결과 화면 출력** | 검색된 물성치 데이터를 가독성 좋은 텍스트 형태(예: `Ultimate Strength: 500 MPa`)로 포맷팅하여 보여줍니다. |
| **MUST** | **프로그램 종료** | 종료 명령을 받으면 CLI 루프(While문)를 빠져나와 프로그램을 안전하게 닫습니다. |
| **NICE**<br>

<br>(있으면 좋음) | **재료 대분류 출력** | `EvenData`에 저장된 데이터들을 강철, 알루미늄 등 상위 종류별 리스트로 묶어 화면에 보여줍니다. |
| **NICE** | **전체 검색 목록 제공** | `EvenData.keys()`를 활용해 현재 검색 가능한 모든 재료의 이름 리스트를 순회하며 출력합니다. |
| **NICE** | **예외 및 오류 처리** | 오타 발생 또는 없는 재료 검색 시 프로그램이 종료되지 않고 안내 문구 출력 후 메뉴로 돌아갑니다. |
| **LATER**<br>

<br>(시간 남으면) | **대소문자/공백 무시** | 'sae2340'이나 'SAE 2340'을 입력해도 동일하게 검색되도록 입력 문자열의 형식을 자동 변환합니다. |
| **LATER** | **물성치 단위 변환** | SI 단위계(MPa)와 영미 단위계(psi)를 상호 변환하여 출력하는 옵션을 추가합니다. |
| **LATER** | **새로운 재료 추가** | 프로그램 실행 중 사용자가 직접 새로운 재료명과 물성치를 딕셔너리에 추가하는 기능을 만듭니다. |

## 2. 데이터베이스 설계안 (`EvenData`)

숫자 데이터와 출력용 단위를 분리하여 유지보수와 추후 확장(단위 변환 등)이 용이하도록 중첩 딕셔너리(Nested Dictionary) 형태로 구성합니다.

```python
# 데이터베이스 역할을 할 딕셔너리 (EvenData)
EvenData = {
    "SAE 2340": {
        "Category": "Carbon Steel",
        "Ultimate Strength": 500,
        "Yield Strength": 400,
        "Density": 7.85
    },
    "AL 6061-T6": {
        "Category": "Aluminum Alloy",
        "Ultimate Strength": 310,
        "Yield Strength": 276,
        "Density": 2.70
    },
    "AISI 304": {
        "Category": "Stainless Steel",
        "Ultimate Strength": 505,
        "Yield Strength": 215,
        "Density": 8.00
    }
}

```

## 4. 화면 흐름 설계 (CLI 목업)

사용자 경험(UX)을 고려한 콘솔 창 기준 텍스트 인터페이스 흐름입니다.

### 4.1 프로그램 실행 및 메인 화면

```text
========================================
    🛠️ 기계재료 물성치 검색 프로그램
========================================
[메뉴]
1. 물성치 검색
2. 재료 카테고리 보기
3. 전체 검색 가능 목록 보기
4. 프로그램 종료
----------------------------------------
원하시는 메뉴 번호를 입력하세요: [사용자 입력 대기]

```

### 4.2 메뉴 '1' (검색) 선택 시 정상 흐름

```text
원하시는 메뉴 번호를 입력하세요: 1

검색할 재료의 이름을 입력하세요 (예: SAE 2340): SAE 2340

--- 🔍 검색 결과: SAE 2340 ---
* Category: Carbon Steel
* Ultimate Strength: 500 MPa
* Yield Strength: 400 MPa
* Density: 7.85 g/cm³
----------------------------------------
(이후 메인 메뉴 다시 출력)

```

### 4.3 예외 상황 (오타 또는 없는 데이터 검색 시)

```text
원하시는 메뉴 번호를 입력하세요: 1

검색할 재료의 이름을 입력하세요 (예: SAE 2340): sae 234

⚠️ 안내: 'sae 234'에 대한 데이터를 EvenData에서 찾을 수 없습니다. 
이름을 확인하시거나 '3. 전체 검색 가능 목록'을 확인해 주세요.
----------------------------------------
(이후 메인 메뉴 다시 출력)

```

### 4.4 메뉴 '4' (종료) 선택 시 흐름

```text
원하시는 메뉴 번호를 입력하세요: 4

프로그램을 종료합니다. 
(프로그램 종료)

```
