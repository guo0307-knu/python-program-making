# 🚀 프로젝트 기획서: 기계재료 물성치 검색 프로그램 (Table Finder)

## 📌 프로젝트 개요

기계공학 전공 문제 풀이 시 필수적으로 요구되는 재료의 물성치(예: SAE 2340 Steel의 극한 강도 등)를 빠르고 정확하게 검색할 수 있는 파이썬(Python) 기반의 검색 프로그램입니다.

##  기획 배경 및 목적

* **비효율성:** 과제나 문제 풀이 시, 두꺼운 전공 서적 맨 뒤의 부록 테이블을 일일이 찾아봐야 하는 번거로움이 존재합니다.
* **가독성 저하:** 방대한 데이터 속에서 원하는 특정 재료와 수치를 눈으로 한 번에 찾기 어렵습니다.
* **시간 소모 최소화:** 단순 데이터 검색에 소요되는 불필요한 시간을 줄이고, 문제 풀이 본연에 집중할 수 있도록 돕는 도구가 필요하여 기획하게 되었습니다.

## ✨ 핵심 기능

1. **🔍 물성치 즉시 검색 기능**
* 사용자가 찾고자 하는 재료의 이름(예: `SAE 2340`)을 입력하면, 해당 재료의 주요 물성치 데이터(Ultimate Strength, Yield Strength 등)를 즉시 화면에 출력합니다.


2. **📂 재료 대분류(카테고리) 확인 기능**
* 데이터베이스에 등록된 재료들의 상위 종류(예: 강철, 알루미늄 합금 등)를 묶어서 직관적으로 보여줍니다.


3. **📋 전체 검색 가능 목록 제공 기능**
* 현재 프로그램에서 조회할 수 있는 모든 재료의 이름을 리스트 형태로 나열하여, 사용자가 어떤 데이터를 찾을 수 있는지 쉽게 파악할 수 있게 합니다.



## 🎯 타겟 사용자 및 서비스 형태

* **예상 사용자:** 본인을 포함한 기계공학부 재학생 및 관련 전공자
* **서비스 형태:** 텍스트 기반으로 가볍고 빠르게 동작하는 **CLI (Command Line Interface)** 프로그램

## 🛠️ 사용 기술 및 핵심 개념

* **개발 언어:** Python 3.x
* **주요 활용 개념:**
* **`Dictionary (딕셔너리)`**: 재료 이름(Key)과 물성치 데이터(Value)를 구조화하여 매핑하는 데이터베이스 역할
* **`List (리스트)`**: 재료의 종류 및 전체 목록을 저장하고 순회(Iteration)하기 위해 사용
* **`Function (함수)`**: 검색, 카테고리 출력, 전체 목록 출력 등 각각의 핵심 기능을 모듈화하여 코드의 가독성과 유지보수성 확보
